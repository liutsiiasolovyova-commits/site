## Уточнения по хостингу и функционалу

### GitHub Pages
- **Возможность загружать свой контент:** Да, GitHub Pages поддерживает статические сайты. Для обновления контента используется:
  - Редактирование Markdown-файлов в репозитории (для статей блога)
  - Система автоматически генерирует страницу из Markdown-файлов
  - Для админ-панели можно использовать Decap CMS (ранее Netlify CMS) — она работает с GitHub и позволяет редактировать контент через веб-интерфейс

- **Telegram бот:** GitHub Pages не поддерживает серверный код. Бот требует отдельного хостинга (VPS, Railway, Render). Пока не требуется.

### Блог
- Статьи хранятся как Markdown-файлы в папке `content/blog/`
- Автоматическая генерация списка статей на главной странице блога
- Поддержка категорий и тегов
