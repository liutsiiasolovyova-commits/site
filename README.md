# Сайт психолога

Лендинг для психологической практики. Сайт создан для привлечения клиентов и предоставления информации об услугах.

## О проекте

Этот проект представляет собой одностраничный сайт (лендинг) для психолога, работающего с подростками и взрослыми.

### Целевая аудитория

- Подростки (15-18 лет) с проблемами взросления
- Взрослые (18-45 лет), ищущие психологическую помощь
- Родители подростков

### Функционал

- Адаптивный дизайн (мобильные, планшеты, десктоп)
- Тёмная/светлая тема (переключатель в шапке)
- Плавные анимации при скролле
- FAQ-аккордеон
- Слайдер отзывов
- Кнопка "Наверх"
- SEO-оптимизация (meta-теги)

### Структура сайта

1. **Шапка** — логотип, навигация, переключатель темы
2. **Hero-секция** — призыв к действию, кнопки
3. **Обо мне** — информация о психологе, статистика
4. **Преимущества** — почему выбирают
5. **Услуги** — консультации для подростков, взрослых, пар
6. **Отзывы** — слайдер с отзывами клиентов
7. **Тарифы** — цены и пакеты услуг
8. **FAQ** — частые вопросы
9. **Контакты** — телефон, Telegram, email
10. **Футер** — копирайт

## Технические детали

## Как редактировать

### Основные данные (в index.html)

- **Имя психолога**: заменить "Имя Фамилия" в нескольких местах
- **Телефон**: `+7 (900) 000-00-00`
- **Email**: `email@example.com`
- **Telegram**: `https://t.me/username`

### Цены и услуги

Редактируются в секции `services` и `pricing` в файле `index.html`.

### Цвета

Цветовая схема задана в CSS-переменных в файле `css/style.css`:

```css
:root {
    --bg: #F8F6FA;           /* Основной фон */
    --accent: #6B5B8C;       /* Акцентный цвет (лавандовый) */
    --accent-green: #5A8A7C; /* Зелёный акцент */
    --text: #2D2438;         /* Основной текст */
}
```

### FAQ

Добавляются в секции `faq` в `index.html`:

```html
<div class="faq__item">
    <button class="faq__question">Вопрос?</button>
    <div class="faq__answer">
        <p>Ответ...</p>
    </div>
</div>
```

### Отзывы

Добавляются в слайдере `reviews`:

```html
<div class="review-card">
    <div class="review-card__text">"Текст отзыва"</div>
    <div class="review-card__author">— Имя, возраст</div>
</div>
```

## Развёртывание на GitHub Pages

1. Создать репозиторий на GitHub
2. Загрузить файлы проекта
3. Настройки → Pages → Source: master/main
4. Сайт будет доступен по адресу `username.github.io/repo-name`
