## Блог

### Как добавить новую статью

**Шаг 1.** Скопируйте шаблон `blog-template.md` в папку `blog/`

**Шаг 2.** Переименуйте файл (например, `my-new-article.md`)

**Шаг 3.** Заполните frontmatter (метаданные вверху файла):

```yaml
---
title: "Название вашей статьи"
date: 2026-07-28
excerpt: "Краткое описание для превью (1-2 предложения)"
tags:
  - тег1
  - тег2
---
```

> Формат совместим с Obsidian: теги — списком, каждый с новой строки.

**Шаг 4.** Напишите текст статьи ниже frontmatter (используя Markdown)

**Шаг 5.** Добавьте имя файла в список `blog/posts.json`:

```json
[
    "anxiety.md",
    "teenager-relations.md",
    "what-does-psychologist-do.md",
    "my-new-article.md"
]
```

**Шаг 6.** Сделайте коммит и запушьте на GitHub

### Формат тегов

Теги совместимы с Obsidian и записываются списком, каждый тег — с новой строки:

```yaml
tags:
  - тег1
  - тег2
```

Знак `#` добавлять не нужно. Тег — одно слово без пробелов. Не перечисляйте теги через запятую.

### Формат Markdown

- `## Заголовок` — заголовок второго уровня
- `**жирный**` — жирный текст
- `*курсив*` — курсив
- `- пункт списка` — маркированный список
- `> цитата` — цитата
- `[ссылка](url)` — ссылка
- `![alt](image.jpg)` — изображение

## Развёртывание на GitHub Pages

1. Создать репозиторий на GitHub
2. Загрузить файлы проекта
3. Настройки → Pages → Source: master/main
4. Сайт будет доступен по адресу `username.github.io/repo-name`
