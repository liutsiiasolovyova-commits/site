**Как добавить статью:**

1. Скопируйте этот файл в папку `blog/`
2. Переименуйте файл (например, `my-article.md`)
3. Заполните frontmatter (метаданные вверху файла между `---`)
4. Напишите текст статьи ниже
5. Добавьте имя файла в массив `files` в файле `js/blog.js`

**Формат тегов (совместимо с Obsidian):**

```yaml
tags:
  - тег1
  - тег2
```

или

```yaml
tags: [тег1, тег2]
```
